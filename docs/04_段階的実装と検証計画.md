# 段階的実装と検証計画

計画日：2026-10-14。対象要件と調査結果を、実装する順番と判定基準に落とし込んだ提案。本書の「完了条件」は今後の判定項目であり、現時点の達成を意味しない。

## 1. 到達点を三つに分ける

| 到達点 | できること | まだ保証しないこと |
|---|---|---|
| M1：カーブと設計の基本版 | 寸法・配合・プロトコル設定、SPMe/DFN、保存・取込・比較 | 全面集電の局所分布、缶応力、対象実セルの予測精度 |
| M2：要求物理を持つ研究版 | 電解液・析出、端面集電の分布熱電気、膨張・力学 | 未測定物性での定量精度、破壊/内部短絡予測 |
| M3：検証範囲を明示できる版 | 実測校正、独立検証、設計探索、再現可能な配布 | 検証外材料・温度・形状への一般化 |

M1はStep 0–3、M2はStep 4–6が中心。Step 7の同定はM1後から着手できる。M3はStep 7–9に加え、対象セルの実測が必要になる。ソフトウェアが動くことと、対象セルで物理的に検証されたことを分ける。

## 2. 実装順序

### Step 0 — 環境・互換性・基準ケースを固定する

**成果物**：別Python環境、依存lock、採用OSS台帳、機能互換表、最小計算スクリプト、公開データの取得記録。

- 現在の `.venv` はPython 3.14。確認した[PyBOP main](https://github.com/pybop-team/PyBOP/blob/main/pyproject.toml)はPython `>=3.10,<3.14`のため、新しいPython 3.12環境を候補に検証する。既存環境は上書きしない。
- PyBaMM・PyBOP・数値ソルバの互換releaseを選び、mainやlatestに追従せず固定する。
- PyBaMMのSPMe/DFN、複合負極、析出、熱、ヒステリシスについて、個別と必要な組合せの最小例を確認する。
- 採用タグ・LICENSE・第三者依存・配布条件を記録する。上流コード、パラメータ、実測データは別々に確認する。
- Chen2020公開例と[公開実測](https://zenodo.org/records/4032561)を取得し、原条件を保った基準ケースを作る。

**完了条件**：新規環境で固定依存から再現でき、基準ケースの結果・終了理由・所要時間が記録される。失敗する機能組合せは理由とともに無効化される。

**実装前に分かっている制約**：NCX/LFP × 黒鉛/複合負極 × 析出 × ヒステリシス × 熱等を、公式例の存在だけで全組合せ対応としない。モデル構築成功だけでなく短い充放電まで実行する。

### Step 1 — データライブラリとUIの骨格

**成果物**：プロジェクト、データ登録、一覧、比較、メタデータDB、原本保存、ジョブ表示。

- [カーブデータ管理仕様](03_カーブデータ管理仕様.md)のCSV/TSV取込、表貼付け・手入力、単位・符号の対応を実装。
- synthetic_demoの短いデータを作り、生成条件とseedを記録。
- 合成・公開実測・ユーザー実測・計算を区別して保存・表示。
- 正規化、比較セット、注釈、原本ハッシュ、再起動後の復元を実装。
- UI入力を変更しても、確定済みの計算条件や保存済みデータが変わらない状態管理にする。

**完了条件**：取込→保存→再起動→表示→比較が一巡する。単位違い、符号違い、時間リセット、欠損を含む例で変換結果が説明できる。まだ物理計算がない画面でも「計算済み」に見せない。

### Step 2 — 円筒設計と材料レシピ

**成果物**：18650/21700テンプレート、巻回断面、寸法・面積・容量・質量収支、設計スキーマ。

- 片面塗工厚、箔、セパレータ、巻回幅・長さ、中心空間、缶寸法を実装。
- 厚み・空隙率・面密度の従属関係、両面の数え方、電極面積と並列数の変換を検証。
- NCX具体組成、LFP、黒鉛、Si、SiOxの材料IDと出典・状態を管理。
- 配合の質量/体積基準、N/P、初期Li在庫、Cレート基準容量を区別。
- 上下端面集電を接続図として入力可能にする。局所分布計算はまだ未対応と表示。

**完了条件**：寸法変更が面積・容量・計算入力へ一貫して伝わる。面積の二重計上や体積超過を検出する。Si=0の設定は一相黒鉛モデルへ変換される。模式図の寸法と設計値が一致する。

**比較PoC**：[STEER OpenCell Design](https://github.com/stanford-developers/steer-opencell-design)と基本的な容量・形状計算を照合する。ライセンスと必要機能を評価した上で、依存採用か独自実装かを決める。

### Step 3 — SPMe/DFNの充放電シミュレーション

**成果物**：計算アダプタ、CC/CV/休止、電流プロファイル、温度条件、結果保存、モデル比較。

- 初期SOC、初期温度、初期化方法、電圧/電流/時間の終止条件を設定できるようにする。
- SPMeを通常操作、DFNを基準として同じ設計・材料・試験から実行する。
- 各材料系は検証済み組合せから順に有効化する。材料データ不足は係数を自動で埋めず明示。
- ソルバ失敗、条件による正常終了、ユーザー取消、上限時間を区別。
- 端子電圧・電流・容量・SOC・温度と、必要に応じ濃度・電位を保存。
- 集中熱と端面集電の等価抵抗を扱う場合、分布計算ではないことを出力に残す。

**完了条件**：設計→条件→計算→保存→公開実測との比較がUIから完結する。メッシュ・許容誤差への依存が確認され、同一条件の再計算が一致する。

**M1の完了**：最初の実用的な基本版。対象の8区分を登録できることと、8区分すべてに校正済み物性があることを区別して公開する。

### Step 4 — 電解液・析出を段階的に追加

**成果物**：物性関数エディタ、電解液濃度比較、局所析出指標、析出/再溶解・Li在庫の結果。

- `D_e、κ、t_+、熱力学因子`の濃度・温度依存、適用範囲と補間を登録。
- 空隙率と輸送効率を扱い、注液量・飽和・電解液濃度を分けて表示。
- まず黒鉛単相の析出モデルで符号・収支を確認し、複合負極へ拡張。
- 析出量、再溶解量、dead Li、SEIによるLi損失を区別。
- SPMeとの比較には電圧だけでなく、局所電解液濃度と析出指標も用いる。

**完了条件**：反応速度をゼロにしたときの析出量ゼロ、Li収支、再溶解・不可逆化の帳尻が合う。条件外物性を黙って外挿しない。析出と熱・複合相の対応が機能互換表に記録される。

**実測がない場合の位置付け**：機構を持つ仮説モデルまで。析出検出精度や安全限界を実証したとはしない。

### Step 5 — 全面集電の電流分布と熱分布

**成果物**：R–z分割、Cu/Al集電路、端面/端板/端子接触、区画ごとの電気化学、異方性熱伝導。

- 最初は少数区画SPMeで収支を検証し、必要領域・代表ケースをDFNと比較。
- 接触面積率、面積比抵抗、正負極それぞれの接続を入力。
- 局所電流・電位・SOC・温度・発熱・析出指標を可視化。
- 領域間の面積、容量、Li量、熱源の移送を保存則に基づいて実装。
- 接触抵抗の発熱を電気化学側と二重加算しない。

**比較PoC**：[JellyBaMM](https://github.com/TomTranter/JellyBaMM)と[BattMo.jl](https://github.com/BattMoTeam/BattMo.jl)を小規模な同一条件で比較し、機能・保守依存・実行負荷から採用判断。独自ネットワーク案も同じ基準で評価する。

**完了条件**：理想均一条件で1D基準へ収束する。端子電流と各経路の電流が保存され、メッシュ細分化で温度極値・局所反応が収束する。接触非均一を与えた際の変化が説明できる。

**限界**：軸対称では周方向の溶接点・接触欠損を均質化する。必要なら周方向分割/3Dを追加し、最初から全らせん3Dを解く設計にはしない。

### Step 6 — 膨張・応力

**成果物**：相別膨張、粒子応力、巻回体の異方性化学ひずみ、缶との接触、軸対称力学。

- 粒子力学と巻回体・缶の力学を別モデル・別結果として実装。
- 初めに一方向連成で、SOC・温度→ひずみ→変位・応力を計算。
- 巻回体の有効弾性、圧縮特性、端部拘束、初期隙間、接触を入力。
- Siの自由膨張からセル径増加への変換には、体積分率・孔隙・拘束を反映。
- 双方向の空隙率・接触抵抗フィードバックは、各物理式と連成収束を確認後に追加。

**完了条件**：一様な自由膨張の無拘束検算、拘束膨張、均一圧力を受ける円筒などで検算できる。接触圧と缶応力を区別し、メッシュ依存を記録する。粒子応力を缶応力として表示しない。

**M2の完了**：ユーザーが挙げた物理領域を持つ研究版。ただし実測のない物性・境界条件は仮定であり、応力や寿命の絶対値には検証が残る。

### Step 7 — 実測同定・不確かさ

**依存**：Step 1–3があれば少数パラメータ同定を先行できる。Step 4–6の係数同定は対応データが得られてから行う。

**成果物**：PyBOP連携、感度・識別可能性、学習/検証分割、候補パラメータ採用、適用範囲。

- 容量・抵抗等の低次元問題から開始し、必要に応じ拡散・反応・熱へ拡張。
- 電圧以外の温度・膨張等は、測定とモデルの対応が確認できたものだけを目的関数に追加。
- セル・温度・レート単位の独立検証を行い、未使用条件への誤差を保存。
- 合成データでの回収試験と、実測での校正・検証を分ける。
- 複数初期値、パラメータ相関、許容範囲、推定の不確かさを記録する。

**完了条件**：推定結果から使用データ・目的関数・版へ遡れる。採用前後の差と検証誤差をUIで比較でき、採用しない場合は既存値が変わらない。

### Step 8 — 設計探索と軽量化

**成果物**：DOE、感度順位、制約付き探索、Pareto比較、必要に応じ縮約/代理モデル。

- 電極厚み、空隙率、N/P、Si比率、電解液、接触抵抗、熱条件を探索変数にする。
- 目的は容量/エネルギー、発熱、析出、膨張・応力、計算条件下の寿命指標を用途別に選ぶ。
- 形状・配合・電圧・温度等の制約を先に定義し、実現不能な設計を計算前に除外。
- SPMeで広く探索し、候補をDFN・必要な分布/力学モデルで再評価。
- 代理モデルは学習範囲を記録し、範囲外は原モデルに戻す。必要があればLiiBRA.jl等を比較。

**完了条件**：採用候補が上位精度モデルで再計算され、代理モデルだけの最適値を最終結果にしない。誤差と速度のトレードオフを実測できる。

### Step 9 — 配布・回帰確認・検証範囲の公開

**成果物**：セットアップ、依存固定、バックアップ/復元、操作マニュアル、検証レポート、既知制約。

- Windowsローカル起動を確認し、FEM workerが必要ならWSL2/Linuxとの接続を別手順にする。
- 長い計算の取消・途中結果、再起動時のジョブ状態、ディスク不足時の扱いを確認。
- 検証済みセル、材料、温度、レート、厚み、モデルオプションの範囲を一覧化。
- OSS/データの出典・利用条件を配布物へ含める。

**完了条件**：別のクリーン環境で基準計算を再現し、プロジェクトを移して原本・条件・結果を辿れる。M3の物理的検証は対象実測が揃った範囲だけを認定する。

## 3. 数値検証と実測検証

以下の数値は**初期の判定値案**であり、今回測定した値でも、どの材料にも使える標準でもない。Step 0–3の基準計算と計測精度を見て確定する。

| 種別 | 確認方法 | 初期の判定方針 |
|---|---|---|
| 設計収支 | 層別体積・質量・面積・容量の独立計算 | 二重面積・負の体積・配合合計不一致を許容しない |
| 電流保存 | 各節点KCL、端子と区画電流 | 残差目安 `max(1e-9 A, 1e-6×基準電流)`、基準を記録 |
| Li保存 | 閉じた系、SEI/析出を含む在庫帳簿 | 相対誤差目安1e-5。収支の対象にdead Li等を含める |
| メッシュ/時間収束 | 少なくとも粗・中・細の3条件 | 電圧差2 mV、容量差0.2%、温度差0.5 Kを出発点にする |
| 局所限界の収束 | 最低電解液濃度、析出指標、局所電流、応力 | 電圧収束だけで合格にしない。閾値近傍は判定が反転しない精度を要求 |
| 熱収支 | 発熱・内部エネルギー・境界放熱 | 源項の二重計上を排除し、離散化誤差として収束すること |
| 力学 | 一様自由膨張、拘束、圧力円筒 | 解析解/独立FEMとの一致、接触・メッシュ収束 |
| モデル間 | 同一設計・物性・初期状態・終止条件 | SPMe/DFNの誤差を温度・レート・厚みごとに記録 |
| カーブ実測 | 未使用セル/試験で比較 | 初期目標例：電圧RMSE20–30 mV、容量差2–3%。対象条件を限定 |
| 温度実測 | 同じ位置・境界・センサ遅れの扱い | 初期目標例：表面温度誤差2 K以内。中心温度を表面実測で直接検証しない |
| 析出・力学実測 | 独立した析出/膨張/荷重等の観測 | 電圧フィットだけで合格としない。データ取得後に基準設定 |

ゼロ電流、短いパルス、休止、CV移行、極端ではない温度差、Si=0、接触抵抗=0などの極限・切替ケースを用いる。各機能の保存則・限界挙動に意味のあるテストを置き、単に実装の数式を複写しただけのテストで精度を保証しない。

不一致が出た際は、材料関数と単位→面積と初期状態→終止条件→離散化→モデル仮定の順に調べる。パラメータ調整で数値不良や面積誤りを隠さない。

## 4. 計算負荷の改善順序

1. **出力制御**：全内部場を全時刻保存せず、必要変数と保存間隔を選ぶ。診断用の高頻度保存は別モード。
2. **再利用**：安全に再利用できるモデル構築・離散化・既知入力をキャッシュ。条件が違う結果を誤用しない。
3. **モデル選択**：SPMeを探索、DFNを基準確認。分布区画数・力学メッシュを収束に必要な範囲へ絞る。
4. **並列化**：独立した条件比較を別プロセスへ。メモリ制限を設け、UIは応答可能にする。
5. **縮約・代理モデル**：検証済み範囲の探索回数が増えた場合に導入。GPU利用は実際のボトルネック測定後。

所要時間は、この調査では未測定。ベンチマークではCPU・RAM・OS・版・モデル・区画/メッシュ数・実験時間・出力条件を併記し、初回構築時間と再実行時間、p50/p95、最大メモリを分ける。異なる許容誤差や機能を使った速度だけでソルバを選ばない。

UIの設計目標は「入力・画面切替は直ちに反応し、重い計算はジョブとして進捗と取消を表示する」とする。計算そのものが常に数秒で終わるとは約束しない。

## 5. 優先する改善と避ける手戻り

| 優先度 | 改善 | 理由 |
|---|---|---|
| P0 | 共通スキーマ、単位・符号・面積・配合基準 | ソルバを増やす前に結果の意味を一致させる |
| P0 | カーブ原本・実行snapshot・出典・種別 | 後から実測が届いても再構築せず校正できる |
| P0 | 物理機能の互換表と材料の適用範囲 | 存在するサブモデルを無条件に組み合わせない |
| P1 | 全面集電の接続・接触・熱境界 | 今回の構造を通常タブセルと区別する中心機能 |
| P1 | 複合負極の二相化とSi/SiOx識別 | 容量倍率だけでは反応分配・膨張が扱えない |
| P1 | 粒子力学と巻回体/缶力学の分離 | 応力の意味と必要データが異なる |
| P2 | 独立実装との数値照合 | 共通バグ・モデル変換誤りの発見に有効 |
| P2 | DOEと感度による実験計画 | 未同定パラメータのために必要な測定を絞る |
| 後期 | らせん完全3D、相分離、濡れ・ガス、分子系連成 | 初期のカーブ管理・DFN基準を確立してから評価 |

## 6. 必要になる実測・物性

| 目的 | 必要なデータ候補 | 今ない場合の扱い |
|---|---|---|
| 電圧/容量 | 複数レート・温度、休止、CC/CV、個体差 | 公開セルで方法を確認し、対象セルは未検証 |
| 材料/電極バランス | 半電池OCP、面密度、厚み、空隙率、配合、利用範囲 | 文献値・仮定を出典付きで登録 |
| 全面集電 | 箔・端板形状、溶接/接触分布、抵抗、境界温度 | 感度範囲を持つ仮定として比較 |
| 電解液 | レシピ、D/κ/t+等のc,T依存、注液・濡れ | 既知レシピの適用範囲内に限定 |
| 析出 | 対応する電位/電気化学診断、必要時の別分析 | 定量的検出性能は未評価 |
| 膨張・応力 | SOC別膨張、温度依存、圧縮特性、拘束条件、荷重/変位 | 仮の弾性・膨張で機構を確認 |

実験計画は、まず一つの基準化学系と一つのセル形式で検証を閉じる。その後18650/21700、NCX/LFP、黒鉛/複合を展開する。8区分を同時に全校正する方針にはしない。

## 7. 工数の見方と最初の着手単位

工数は未見積の不確実性が大きい。計画上の仮置きとして、電池モデルに詳しい担当者の支援を受ける開発者1名で、M1は6–10週、Step 4–6の研究版は追加8–16週、同定・探索・配布の整備は追加4–8週程度を初期の検討幅とする。実装範囲、既存モデルの互換性、力学の接触モデル次第で延びる。実測取得・材料同定・対象セルの精度保証は別工数であり、この期間に含まれない。

最初に具体化する作業単位は**Step 0とStep 1**とする。完了時に、依存版、実行できたモデル組合せ、基準カーブ、公開データ取込、保存・比較の画面がレビューできる。それを確認してから設計入力と分布物理を広げる。

現時点の成果は調査・仕様・実装計画であり、インストール、ソルバ実行、ダミーデータ生成、UI構築、実測比較はいずれも未実施である。
