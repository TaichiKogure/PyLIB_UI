# Step 2 — 円筒設計・材料レシピの実装と検証

更新日：2026-10-15（日本時間）。基本版v0.3。設計見積りと入力管理の実装であり、実セルの予測精度や製造可能性の認証ではない。

## 1. 実装範囲と操作

`start.ps1` で起動し、画面上部の「円筒設計・材料レシピ」を使用する。既存サーバーが動いている場合は終了して再起動し、ブラウザーを再読込する。

1. プロジェクトを選ぶ。21700／18650を選択し「テンプレートで入力を置換」で初期設計を入れる。
2. 「寸法・巻回構造」で缶、蓋、中心空間、隙間、巻回幅、塗工幅、片面塗工厚、箔・セパレータを指定する。長さは有効径までの自動計算、または指定長から選ぶ。
3. 「材料と乾燥固体配合」でNCXの具体ID（NMC811／NCA 80:15:5）またはLFP、黒鉛とSi／SiOx、結着剤、導電助剤を選ぶ。配合合計は各極で1。孔隙を乾燥固体配合へ混ぜない。
4. 質量／体積の入力基準を選ぶ。切替は同じ入力数値の再解釈であり、入力欄の自動変換ではない。換算後の両方の分率は「材料・相変換・計算アダプタ入力」で確認できる。
5. 初期Li充填率、Cレートの基準（設計／指定定格）、注液率、その他部品質量を設定する。上下の集電端面、正負それぞれの接触面積率を指定する。
6. 自動更新された断面、面積、面密度、容量、N/P、体積、質量、注意表示を確認する。不正な設計では古い収支を消し、保存と反映を停止する。
7. 「設計を新しい版として保存」を押す。保存済み設計のドロップダウンから復元できる。編集後の保存は別IDの新しい版となり、前の版を変更しない。
8. 「保存した設計を試験条件へ反映」で外径・全高・形式・Cレート基準容量・模式曲線を既存の合成モデルへ渡す。LFPはLFP模式曲線、NMC/NCAはNMC模式曲線へ対応する。NCA専用OCVではない。合成モデルの範囲外では反映を停止する。
9. 試験条件を変更して実行し、必要ならカーブを保存する。設計連携中の実行結果には設計全体のスナップショットが付く。直接寸法・容量・正極系を変更すると連携を解除する。

設計JSONは未保存プレビューでも書き出せる。DB内の確定版は明示保存時のみ作成される。設計JSONの再取込・設計削除・任意物性の編集・材料追加UIは今回未対応。保存先は既存
`data/runs.sqlite3` の新しい `designs` テーブルで、既存カーブ・原本・比較セットを変更しない。バックアップはサーバー停止後のdataフォルダー全体コピー。

## 2. 収支と単位の定義

設計スキーマは `design-2.0`。寸法mm、片面塗工厚・箔・セパレータµm、材料密度g/cm³、比容量mAh/g、質量g、容量Ah。JSONのキーで単位を固定する。

- 周期厚：`pitch = (2*t_p + Al + 2*t_n + Cu + 2*separator)/1000` mm。両面塗膜を2回、箔を各1回、セパレータを2枚数える。
- 有効半径：`R = 外径/2 - 缶壁 - 径方向隙間`、中心半径 `r = 中心径/2`。
- 自動長：`L = π(R²-r²)/pitch`。指定長では `巻回外半径 = sqrt(r² + L*pitch/π)`
  。連続環状近似で面積を保存する。巻数は半径差/pitchで、製造時の整数巻き・開始角・端部とは一致しない。
- 塗工面積：各極 `A = 2*塗工幅*L`。箔とセパレータ幅は巻回幅と共通。正極幅≤負極幅≤巻回幅、巻回幅≤全高−予約高さを要求する。
- 質量基準の固体密度：`ρ = 1 / Σ(w_i/ρ_i)`。体積基準では `ρ = Σ(v_i*ρ_i)`。成分の体積加算を仮定する。
- 塗膜体積：両面面積×片面厚。乾燥質量：塗膜体積× (1−空隙率)×固体密度。面密度は乾燥固体全量/塗工面積、面容量は面密度×配合比容量。
- 正負の半電池容量：乾燥質量×配合比容量。負極全体容量と、正極幅に重なる負極容量を分ける。`N/P = 負極重なり容量/正極容量`
  、設計容量は両者の小さい側。負極の余剰幅を増やしてもN/Pや設計容量を過大評価しない。
- 設計容量は初期Li、利用率、電圧窓を考慮した取出容量ではない。Cレート基準に指定定格容量を使っても、設計容量の見積りは書き換えない。
- 初期Li帳簿：各極半電池容量×初期充填率をAh等価量として保持。合計×3600/Fでmol等価量。SEI・不可逆損失・電解液Li・絶対化学量論・平衡電位を含まない。既存ECMの初期SOCとは独立した保存項目。
- 巻回外形体積は構成層体積＋塗工幅の差による未塗工部空間。孔隙は塗膜とセパレータ内部に含まれ、外形体積へ二重加算しない。電解液は孔隙体積×充填率のみとし、未塗工空間や缶内の余剰液は自動加算しない。
- 質量内訳：正負乾燥塗膜、Al箔、Cu箔、セパレータ固体、注液、缶・上下蓋、その他部品。缶・蓋の体積は外円筒から内円筒を差し引く。蓋の実体厚と、端板・空間を含む予約高さを分け、予約高さ全体を金属質量にしない。

缶は鋼7.85、Al2.7、Cu8.96、セパレータ固体0.94 g/cm³の仮定。物性は `design.py` のID・出典・`illustrative_unvalidated`
状態とともに保存する。正負活物質やSiOxの物性も仮定値であり、原著から校正した値ではない。SiとSiOxを同一材料へ読み替えない。

## 3. 後続ソルバへの境界

`adapter_input`
は正極塗工幅を等価電極height、巻回長をwidth、両面をparallel_electrodes=2として面積を再構成する。塗工面積を渡したうえで並列数をさらに乗じない。外形高さと等価電極heightは別物。

Si/SiOxが0なら、活物質リストから第2相を除き、黒鉛単相 `negative_particle_phases="1"`
へ変換する。非ゼロなら2相。乾燥固体体積分率と、孔隙を除いた電極内相体積分率も区別して出力する。

現時点の `solver_ready`
はfalse。SPMe/DFNへ物性・相別初期化を渡す本番アダプタはStep3。上下端面集電は接続経路を指定・保存するだけであり、接触率から抵抗や局所発熱を捏造しない。未校正の設計を、既存Chen2020の校正済み寸法や物性であるかのように使用しない。
