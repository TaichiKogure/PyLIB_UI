# PyBaMM全機能一覧とUI実装計画

作成日: 2026-10-16。対象: PyLiBStudy、固定研究環境 **PyBaMM 26.10.1.0**。

## 1. 対象と読み方

「全機能」は、利用者が選択・実行・観察する機能領域と、固定版が公開するモデル・設定キー・パラメータセット・ソルバ・試験ステップを対象とする。内部の全クラスや将来追加される任意の方程式までを有限のUI項目として列挙する意味ではない。公開APIの全候補は[自動抽出一覧](evidence/PyBaMM_固定版API全候補.md)
、機械可読版は[JSON](evidence/pybamm_capabilities_26.10.1.0.json)を参照する。

固定環境を実際に読み込み、5モデル名前空間、39設定キー、19パラメータセット、10ソルバクラス、25ステップ関連公開名を記録した。基底クラス・補助クラスも含むため、この数は実行可能な独立機能数ではない。
`lithium_metal`には抽出対象となる公開フルモデルクラスがなく、半セル・界面サブモデル側で扱う。

以下の機能表は現在の `physics.py`、`physics_worker.py`、`jobs.py`、画面コードと固定版のソースを照合した開発用バックログである。

- **対応**: 現在のUI・バックエンドに経路がある。全材料・条件での精度保証ではない。
- **一部**: 経路が限定される、または別の模式計算でありPyBaMMの当該機能とは別。
- **未**: PyBaMMのAPIまたはモデル構成で扱えるが、UIは未接続。
- **調査**: 特定のモデル・追加依存・OS・物性・境界条件で成立するか先に確認する。

公式 `latest`
は閲覧時に26.10.1.1開発版を表示した。文書の例を固定版の対応証拠としては使わず、固定ソースの存在と短い実行試験を別に確認する。特に各選択肢の直積は実行できない。材料名が一覧にあるだけでは必要な劣化・熱・力学物性がそろうとは限らない。

## 3. UIの配置と共通契約

上位導線を **設計 → 材料・モデル → 試験条件 → 実行 → 結果 → 実測比較**
とし、同じプロジェクト・設計版・材料版・計算条件を引き継ぐ。劣化、EIS、一括比較は用途別の補助画面とする。高度な数値設定は折りたたみ、全オプションの巨大なプルダウンにはしない。

実行前に「モデル×物性×熱×劣化×相数×ソルバ×OS」の互換表を評価する。選べない組合せは理由と必要な物性を表示する。APIでも同じ検証を行う。任意Pythonコードの貼付け実行は設けず、独自関数は信頼済みローカル登録方式とする。

全結果にエンジン版、モデル、設定、物性差分/出典、入力原本ハッシュ、設計版、ソルバ、メッシュ、許容誤差、終了理由、検証区分を保存する。合成、未校正仮想セル、公開実測、自社実測を継続して区別する。未知変数は無言のゼロ埋めをせず「取得不可」とする。分布結果は単位・座標・次元を一緒に保存し、サイズ上限と間引きを設ける。

## 6. Windowsでのダブルクリック起動

- フォルダー直下の **`PyLiBStudy.lnk`（電池アイコン）** または **`start.cmd`** をダブルクリックする。
- ブラウザーが自動で `http://127.0.0.1:8765` を開く。終了は起動コンソールでCtrl+C。ブラウザーを閉じても計算サーバーは残る。
- 同じ作業フォルダーのサーバーが起動済みなら再利用する。他アプリや他フォルダーのサーバーは終了しない。ポート使用中などの失敗時はエラーを表示してキー入力待ちにする。
- `.venv`のPythonを優先し、なければWindowsの`py -3`を使う。通常UI用Pythonは3.10以上、物理計算は既存の`.venv-research`
  が必要。自動インストールや環境更新は行わない。
- **2026-10-16再構築:** 当初のPowerShell経由のバッチを、Python直接起動に変更し、ExecutionPolicy
  Bypass指定を削除した。利用者による対策後に書込みと起動検証が成功。Norton設定・ファイル権限は変更していない。以前の検知との因果関係・誤検知かどうかは未確定。[検証記録](12_Windows起動再構築の状況.md)
  参照。
- ショートカットは絶対パスを持つため、フォルダー移動後は再生成する。`.lnk`はローカル生成物、アイコンと生成スクリプトはリポジトリで管理する。

再生成:

```powershell
powershell.exe -NoProfile -File .\scripts\create-windows-shortcut.ps1
```

デスクトップに置きたい場合は、作成済み`PyLiBStudy.lnk`をコピーする。または利用者自身が次を実行する（今回の作業ではプロジェクトフォルダー内に作成）。

```powershell
.\scripts\create-windows-shortcut.ps1 -Destination ([Environment]::GetFolderPath('Desktop'))
```
