# PyBaMM機能拡張 P2 実装と検証

実施日: 2026-10-17。資料11のP2を実装した。P0/P1の実行経路を維持し、固定環境 PyBaMM 26.10.1.0 /
IDAKLUを使う。依存ライブラリの追加・更新はしていない。

## 1. 完了範囲と操作

1. 既存サーバーを終了して `start.cmd` で再起動し、ブラウザーを再読み込みする。
2. SPM/SPMe/DFNの試験欄で「結果変数・x/r分布・初期OCV・参照電極」を開く。追加系列、分布変数、保存時刻数・座標点数を選ぶ。基本7系列は常に保存する。
3. 初期OCVを入力すると初期SOC入力が無効になる。空欄なら従来のSOC指定。参照位置はセパレータ内の割合0.05〜0.95、既定0.5。空欄で挿入しない。
4. 計算結果の「結果系列」で単位・取得状態付きの系列を選ぶ。「結果を詳しく見る」で平衡電極SOH、容量・エネルギー、条件付き効率、時刻別の電圧損失・発熱成分、x/r分布を確認する。
5. 保存された計算結果・取込カーブには、平滑化窓・微分閾値・パルス遅延・最小休止時間を指定して後処理を実行できる。取込直後のプレビューは先に「保存」する。保存後に後処理ボタンが有効になる。
6. 残差比較は同じプロジェクトに保存した取込カーブと計算結果を選び、双方の区間と時間ずれを明示する。電圧・電流・温度を比較でき、RMSE・平均絶対誤差・平均残差・最大絶対残差と電流/温度の条件照合を表示する。
7. 後処理・残差は別の解析レコードとして保存する。「保存した解析」から再表示し、解析CSV/JSONを出力できる。元の結果・取込原本は書き換えない。

## 2. 結果契約と来歴

- 条件スキーマは **1.2**、ワーカーは **1.4.0**、結果スキーマは **3.1**、結果変数/分布契約は **1.0**
  。版なし・1.0・1.1の条件は入力を変異させず移行し、将来版は拒否する。
- スカラーは基本7＋追加22変数。追加系列は選択可。各変数に日本語名・PyBaMM変数名・単位・次元・取得状態・理由を付ける。モデルに存在しない選択変数は
  `null`、未選択は系列を保存しない。0で補わない。
- 分布11種: 電解液濃度/電位、正負極固相電位/反応電流密度、セル温度のx分布、正負極粒子濃度と複合負極主相/副相粒子濃度のr分布。モデルにないものは取得不可になる。
- r分布はx平均であり、x×r場ではない。xは厚さ方向、rは球形粒子半径。SPMのx分布や等温/集中熱の温度分布は縮約モデルの一様値で、局所温度予測を意味しない。
- 座標はネイティブの物理メッシュ節点を明示して評価する。保存単位m、画面表示μm。保存時刻は出力点の番号を均等選択して両端を含め、各フレームに元の点番号・時刻・区間を保持する。座標は節点を選び、空間外挿しない。
- 分布は2〜61時刻、5〜80座標点/変数。最大11×61×80=53,680個の分布値。間引いた節点番号と元点数を保存する。基本の時間点上限12,050は維持。
- JSONは全結果、通常CSVは保存スカラー系列、分布CSVは変数・座標・元節点番号・時刻・区間・値の縦持ち形式。後処理CSVはderivatives/pulses/gittの区分を付ける。
- 計算CSVの再取込には専用の `simulation_import` 種別を追加した。出典必須で、実測へ自動的に分類しない。元CSVのバイト列・SHA-256と取込変換は従来どおり保持する。
-
解析はSQLiteの独立テーブルに保存し、プロジェクトで隔離する。元入力、点列ハッシュ、原本メタデータ、出典・ライセンス・測定位置・変換履歴を解析スナップショットに保持する。ページ再読込・プロジェクト切替後の古い非同期応答で表示を上書きしない。
- 引用は隔離ワーカー内で登録された固定版の引用キーを、同梱 `CITATIONS.bib`
  の原文に対応させる。同梱辞書のSHA-256・解決できなかったキーも記録する。pybtex追加インストールは行わない。

主なAPI: `GET /api/result-catalog`、`POST /api/analysis/postprocess`、`POST /api/analysis/compare`、`GET /api/analyses`、
`GET /api/analyses/<id>[.json/.csv]?project_id=...`、`GET /api/results/<id>.spatial.csv` / `.bib`。

## 3. 数式と適用条件

**電極SOH:** PyBaMMの `ElectrodeSOHSolver`、複合負極では `ElectrodeSOHComposite.solve_full`
を使う。電圧窓で決まる平衡容量と化学量論であり、定格容量や実測寿命SOH (%)
ではない。複合相は相容量で重み付けして初期SOCと負極の利用窓容量を得る。計算できない場合は取得不可とし、OCV初期化に必要なSOCも得られなければジョブを失敗にする。

**初期OCV・参照電極:** OCV初期化はPyBaMMの電圧文字列による初期化を使用し、SOC帳簿の初期値もeSOHから導出する。参照電極は
`insert_reference_electrode` で挿入する。3E電位の正極−負極と端子電圧の一致を実計算で確認した。参照位置の電解液電位と正負極3E電位を混同しない。

**容量・エネルギー:**
同一区間の隣接点でI,Vを線形として積分する。符号が変わる場合はI=0で分ける。充電/放電Ah・Whを別集計する。欠損・区間境界は積分しない。初終SOC帳簿差≤0.005、充放電の両方があり、欠損区間がない場合だけ効率比を出す。完全サイクル効率の実証ではない。

**収支:** 表面OCV＋反応＋電解液オーム＋濃度＋固相オーム成分と端子電圧を比較する。発熱はオーム＋不可逆反応＋可逆反応＋ヒステリシス＋混合熱と全発熱を比較する。全点の成分が揃った場合だけ判定する。許容差は電圧1e-4
V、発熱1e-6 W。接触抵抗熱や混合熱の新しい物理モデルは有効化していない。

**微分:**
1〜31の奇数窓でQ,Vそれぞれの中心移動平均を取り、その中心差分割線からdQ/dV・dV/dQを計算する。Qは絶対通過容量、V差には符号を残す。窓端・休止・充放電反転・容量非増加・欠損・区間境界を跨がない。最小ΔV/ΔQ未満は取得不可。設定と方法を解析に保存する。

**パルス:** 電流変化の直前点を基準に `R=-ΔV/ΔI`
を評価する。指定遅延時刻が変化後の同一区間・定電流窓内にある場合だけ隣接点間補間する。欠損、短すぎる窓、大きな基準時間欠落は取得不可とし、負の抵抗値も隠さない。規格DCIRを保証する計算ではない。

**GITT型:** 定電流区間の前後に指定長の休止がある場合だけ、パルス始終電圧差ΔE_p、前後休止の最終電圧差ΔE_rest、V対sqrt (t)
の回帰傾き、`(ΔE_rest/ΔE_p)^2/パルス時間` (1/s) を出す。休止における平衡到達を保証せず、形状・活物質量なしで拡散係数Dを計算しない。ステップ境界の浮動小数点丸めは1e-8秒まで許容する。

**残差:** `計算時刻=取込時刻+指定時間ずれ`
。双方の区間を明示し、計算側の隣接点だけで線形補間する。重複・非昇順時刻は拒否し、欠損や区間境界を跨がず外挿しない。除外点数も記録する。残差は計算−取込。電流/温度は許容差を照合し、温度の測定位置・初期状態・材料/設計・対象セルは手動確認と表示する。合成・再取込計算曲線との比較を実測精度検証とは扱わない。
