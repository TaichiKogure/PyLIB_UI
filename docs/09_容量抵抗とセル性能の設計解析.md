# 活物質容量・抵抗・セル性能の設計解析と検証

更新日：2026-10-16。基本版v0.5。設計スキーマ `design-2.1`、解析版 `design-screening-1.0`、物理計算アダプタ `1.1.0`。

Step 3に続き、設計を変更したときの容量・抵抗・性能の関係を強化した。これはStep 4の電解液輸送へ進むための設計解析と、Step
5の集中集電近似の先行実装である。析出量の時間発展、電解液物性関数の編集、R–z局所分布、測定DCIRとの校正は含まない。

## 1. 操作

起動中の旧サーバーを終了して `start.ps1` から再起動し、ブラウザーを再読込する。

1. 「共通の円筒設計」を選ぶ。寸法・巻回構造と材料・配合を指定する。
2. 「活物質の比容量・利用率・形成損失」で正極・黒鉛・Si/SiOxの **可逆比容量**を入力する。0は材料の既定仮定値を選ぶ指定で、活物質を無容量にする意味ではない。
3. 比容量を乾燥固体の配合と組み合わせる。質量配合と体積配合は区別する。利用率はユーザーが指定する値で、レートから自動推定しない。
4. 「上下端面集電の接続」で接触面積率、箔端面の面積比抵抗ASR、端板・端子等の直列抵抗を指定する。
5. 「電解液輸送・電子伝導・反応・拡散の仮定」でκ、Bruggeman指数、有効σ、等価粒子半径、交換電流密度i₀、固相拡散係数Dを指定する。各値は評価SOC相当・温度での入力と解釈する。
6. 「性能見積りの評価点・平均熱収支」で固定A／固定Cレート、評価OCV、下限電圧、温度、パルス秒数、比熱、熱伝達係数を設定する。LFP等のOCVは材料名から自動推定しないため、評価条件に合わせて手動で指定する。
7. 下部の容量・Li帳簿・抵抗・発熱カード、活物質別の容量寄与、抵抗内訳、輸送物性を確認する。
8. 感度グラフの指標を切り替え、13項目×±10%の差分を見る。「比較の数値・変更値・計算できない理由」で変更後の値、電流、巻回長、容量、N/P、抵抗、電圧、発熱を確認する。
9. 「設計を新しい版として保存」で入力・材料物性・解析版・数式・文献・比較結果を保存する。「設計JSON」でも同じ情報を書き出せる。

入力が不正になった時点で古い結果を消し、保存・書出しを無効にする。通信応答が前後しても新しい入力版だけを採用する。既存の保存版は再計算で上書きしない。解析追加前の保存版を開いた場合は「この設計を新しい式で再評価」を押し、新しい版として保存する。旧版にない項目は既定値に戻し、直前の編集値を引き継がない。

## 2. 活物質容量とセルの容量帳簿

理論比容量は `q_theory = n F/(3.6 M)`。Fは96485.33212
C/mol、Mはg/mol、出力はmAh/g。NMC811/NCAは全1Li、LFPはLiFePO₄→FePO₄、黒鉛はLiC₆、元素SiはLi₁₅Si₄の反応を基準にする。実装中の原子量から、黒鉛は約371.9、Siは約3578.6、LFPは約169.9
mAh/gとなる。これらは反応式の上限であり、実用電圧窓での可逆容量ではない。[Sternadら](https://www.nature.com/articles/srep31712)
は黒鉛・Siの反応終点と理論比容量の根拠となる。

SiOxはxと反応機構が未指定なので、理論比容量を算出しない。指定可逆容量は別に保持する。指定値が表示反応式の理論上限を超えた場合は警告し、黙って上限へ切り詰めない。

乾燥固体の混合密度と容量は次の関係を使う。

```text
質量配合: ρsolid = 1 / Σ(wi/ρi), vi = (wi/ρi) ρsolid
体積配合: ρsolid = Σ(vi ρi), wi = vi ρi/ρsolid
qmix = Σ(wi qi)
A = 2 × 塗工幅 × 巻回長                    [cm²へ換算]
mdry = A × 片面厚 × (1−空隙率) × ρsolid   [g]
Q = mdry qmix / 1000                     [Ah]
qareal = 片面の乾燥面密度 × qmix / 1000   [mAh/cm²]
```

各活物質の質量と容量寄与を保存する。成分容量の合計は電極全体容量に一致する。負極余剰幅の容量は全体容量に含めるが、N/Pとセル容量では正極との重なり領域へ縮約する。

```text
Qp,u = Qp × 正極指定利用率
Qn,u = Qn,overlap × 負極指定利用率
設計容量 = min(Qp,u, Qn,u)
利用率込みN/P = Qn,u / Qp,u
```

従来の `np_ratio` は利用率前の値を保持し、`usable_np_ratio` を追加した。指定定格容量と設計容量は別に保存する。

形成損失の比較用に、ICE＝脱離容量/挿入容量として次の **独立した工学帳簿**を設けた。

```text
Qloss = Qn,u (1/ICE − 1)
Qbalance = max(0, min(Qp,u − Qloss, Qn,u))
Enom = Qbalance × 指定OCV
```

負極の指定利用窓全体を形成し、その不可逆Liを正極から供給、予備Liなしとする仮定である。既存の初期Li充填率帳簿とは結合していない。実際の形成プロトコルやOCV窓を解いた結果ではなく、Si比率増加とICE低下の影響を比較するために使う。Enom、Wh/kg、Wh/Lも一定電圧の帳簿値で、放電曲線の積分エネルギーとは異なる。

## 3. 抵抗内訳の導出と単位

内部はSI単位、表示はmΩ。電極反応面積 `A = 2×正極塗工幅×巻回長` を一度だけ使う。セパレータの枚数をさらに2倍しない。両面から電流が入る集電箔も1枚である。

### 孔内輸送と電子伝導

```text
κeff = κ ε^b             [S/m]
屈曲度因子 τ = ε^(1−b)
R孔内電極 = L / (3 κeff A)
Rセパレータ = Lsep / (κeff,sep A)
R固相電極 = L / (3 σeff A)
```

Bruggeman指数bの既定1.5は仮定。[PyBaMMの輸送効率の定義](https://docs.pybamm.org/en/latest/source/examples/notebooks/models/tortuosity_models.html)
に従い `ε/τ=ε^b` とする。[Landesfeindら](https://doi.org/10.1149/2.1141607jes)
が示すように、実電極の輸送を単純な球形近似で再現できるとは限らない。有効σは配合から捏造せず独立入力にした。

電極内で一様に反応する場合、各相の電流は厚み方向に線形に変化する。`P = ∫i(x)²/(κeff A) dx` を端子電流Iについて `P=I²R`
に換算すると係数1/3になる。これは本実装の損失積分による導出で、DFNの解や任意の反応局在に対する一般式ではない。セパレータでは全電流が通るため1/3を付けない。

注液充填率<1、または正負極・セパレータいずれかの空隙率=0では、この輸送則を適用しない。容量・質量計算は保持し、抵抗・性能はnullと理由を出力する。Infinityを保存せず、濡れ不足の性能を任意係数で作らない。

### 反応分極と粒子拡散

```text
as = 3 εactive / r
I0 = i0 as L A
ηct = (2RT/F) asinh(I/(2I0))
Rct,割線 = ηct/I ; I=0ではRT/(F I0)
拡散時間 = r²/Ds
```

対称Butler–Volmerの静的近似。i₀は活物質表面積基準A/m²であり、幾何面積基準ではない。複合負極ではユーザー指定の等価i₀・r・Dを全活物質体積に用い、相別の反応分配は解かない。
`r²/D`
と容量帳簿の放電時間との比を表示するが、その比から経験的なレート容量減少を自動生成しない。反応・輸送を動的に解く場合はSPMe/DFNを使う。[Doyleら](https://doi.org/10.1149/1.2221597)
が多孔質電極モデルの基礎となる。

### 端面集電・接触・端子

```text
R箔,端面 = ρ H / (3 t ℓ)
R箔,長手比較 = ρ ℓ / (3 t H)
Aedge = t ℓ
Rcontact = ASR / (接触率 × Aedge)
```

Hは各極の塗工幅、ℓは巻回長、tは箔厚。未塗工リード長0、片側の連続端面集電、一様注入を仮定した損失積分である。箔の抵抗率は室温の工学仮定としてAl
2.82×10⁻⁸、Cu 1.68×10⁻⁸ Ωmを使う。温度による抵抗率補正は未実装。

接触ASRの入力単位はΩ·mm²、Aedgeはmm²に換算する。これは箔の切断端面積であり、巻回円板全体の面積ではない。溶接の実接合面積を測定したことにはならない。接触率は接触項だけに作用し、箔抵抗や局所縮流を自動変更しない。

長手集電は全幅接続の理想比較で、端面集電抵抗へ加算しない。タブ点数・配置・溶接・端板内の分布は未計算。[Tranterら](https://discovery.ucl.ac.uk/id/eprint/10118283/)
は集電経路の変更が電気・熱挙動に影響することの原著参考であり、本式を同論文の数式として転載したものではない。

端板・端子等は指定の直列mΩ、皮膜は正負合計のASR Ω·cm²を幾何反応面積cm²で割る。

## 4. 性能・熱と感度比較

```text
ΔV = I Rohmic + Σηct
Vterminal = Uref − ΔV
Pterminal = I Vterminal
Qdot,irreversible = I ΔV
Cth = セル質量kg × cp
G = h Aexternal
ΔT = Qdot/G × (1−exp(−G tpulse/Cth))
G=0では ΔT = Qdot tpulse/Cth
```

初期温度＝周囲温度、一定損失・一定物性の平均熱収支。小さいGでの桁落ちを避けるため `expm1`
を使う。[Bernardiらの一般熱収支](https://escholarship.org/content/qt9fx5f0h8/qt9fx5f0h8.pdf)
の全項を実装したものではなく、可逆熱・混合熱・濃度分極・局所温度を省略する。下限電圧以下、またはパルスが容量帳簿の放電時間を超える場合は注意を表示する。負の端子電圧では出力値をnullにする。

感度比較は正極比容量、黒鉛比容量、正負厚み、正負空隙率、Al/Cu箔厚、セパレータ厚、κ、正負接触率、負極粒子半径の13項目。それぞれ1項目だけ±10%変更する。

- `fit` では変更ごとに巻回長を再計算する。厚膜化で面積が減る効果も含む。
- 固定Aと固定Cレートを区別し、実際の比較電流も記録する。指定定格容量基準の場合はCレート電流が設計容量に連動しない。
- 制約違反は変更値と理由を保存する。接触率1の+10%を黙って1へ丸めない。
- 比容量だけを変えても、固定A・固定物性での抵抗が変わらない場合がある。容量やN/Pの変化と抵抗変化を同じ係数で結び付けない。

厚みと空隙率の設計トレードオフの原著参考は[Newman 1995](https://doi.org/10.1149/1.2043956)。同論文の最適値を21700へ直接転用していない。

既定21700の仮定例は、設計容量4.27087 Ah、5 A、等価抵抗10.7403 mΩ、電圧降下53.7013 mV、不可逆発熱0.268507 W、60秒の平均温度上昇0.245284
K。対象セルで測定した値ではない。18650例も含めて[解析JSON](evidence/design-analysis/analytical-examples.json)へ保存した。

## 5. SPMe/DFNの実計算との接続

保存設計を物理計算で選択すると、寸法・空隙率・活物質相分率・Cレート基準容量は既存アダプタを通して反映する。比容量・利用率を変え、設計容量をCレート基準に選んだ場合、公称基準容量も変わる。しかし文献セットのOCV、最大Li濃度、拡散・反応関数を比容量から作り直すことはしない。設計帳簿容量とソルバの電圧窓容量は一致するとは限らない。

設計画面のκ・σ・i₀・D・粒子半径・ICE・集中抵抗は **解析用の入力**
で、SPMe/DFNの文献物性を上書きしない。[Chenらのパラメータ化研究](https://doi.org/10.1149/1945-7111/ab9050)
にある測定・同定を、本画面の仮定入力で代替したとは扱わない。

新規の物理計算結果には以下のソルバ変数11項目を各時刻で保存し、初期・最終・出力表示点の最小最大を画面の結果詳細で表示する。CSVとJSONでも保持する。
