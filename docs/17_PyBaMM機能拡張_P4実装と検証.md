# P4 材料物性・半セル・輸送設定の実装と検証

2026-10-17 / PyLiBStudy / 固定PyBaMM 26.10.1.0・IDAKLU・Windows

## 実装した内容

「試験」画面の **材料物性・差分・粒子/輸送・ヒステリシス・BPX** から設定する。

| 機能                 | 実装範囲と条件                                                                                                                                                                                                                |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 標準物性の閲覧・比較 | 固定環境の19セット。数値、出典ID、説明、同梱関数名とソースSHA-256を検索・比較。未収録値をゼロ補完しない。閲覧可能な全セットが実行可能という意味ではない。                                                                     |
| LFP                  | Prada2013、SPM/SPMe/DFN、等温。文献容量2.3 Ah、既定電圧窓2.0–3.6 V。熱物性不足のため熱源・混合熱を拒否。                                                                                                                      |
| NCA                  | NCA_Kim2011、SPM/SPMe/DFN、等温。文献容量0.43 Ah、既定電圧窓2.7–4.2 V。                                                                                                                                                       |
| 複合負極             | Chen2020_composite・DFN。負極2相、Siのcurrent sigmoid/one-state hysteresis/one-state differential capacity hysteresis。状態ヒステリシスの初期状態・減衰係数等は出典付き入力が必須。既存の集中熱条件を維持。                   |
| 半セル               | Xu2019・DFN・等温、LCO正極/Li金属対極。文献容量0.0024 Ah、既定電圧窓3.5–4.2 V。全セル用参照電極位置は空欄。専用eSOHで初期化学量論・電圧窓平衡容量を取得。                                                                     |
| 粒子内拡散           | 球形、Fickian diffusion/uniform profile/quadratic profile/quartic profile。no particles/MSMRは対象外。                                                                                                                        |
| 輸送効率             | Bruggeman、tortuosity factor、ordered packing、hyperbola of revolution、overlapping spheres、random overlapping cylinders、heterogeneous catalyst、cation-exchange membrane。tortuosity factorは電極/電解液の追加係数が必須。 |
| 方向別物性           | diffusivity/exchange-current densityのcurrent sigmoid。各電極・相のlithiation/delithiation物性を明示する。                                                                                                                    |
| 独自物性             | 単位付きPyBaMM名と数値の差分。OCPは化学量論0–1全域を覆う3–1000点の昇順表。線形補間、範囲外の外挿なし。数値の有限性・正値・分率合計・未知物性を検証。                                                                          |
| 関数                 | 固定版に同梱された関数を登録済み物性として使用。任意Pythonのアップロード・貼付け実行は設けない。独自関数の追加登録UIは対象外。                                                                                                |
| BPX                  | BPX 1.x、完全DFN物性・単相・等温。文献セットへ無言で不足値を混ぜない。500KB以内のJSONファイルを取り込む。数値・表・制限付き算術式をネイティブParameterValuesへ変換。                                                          |

材料の変更時はUIの電圧窓を文献値に更新する。差分・試験プロトコルは保持するため、切替後に内容を確認する。APIでも新規採用セットの電圧窓を省略した場合は文献初期値を使い、明示入力は保持する。

## 来歴・容量・初期状態

設定スキーマは **1.4**、アダプタは **1.6.0**。版なし/1.0/1.1/1.2/1.3を新設定へ復元でき、旧結果を書き換えない。

独自差分の変更前/採用値、出典、入力設定SHA-256、基準物性インベントリSHA-256を結果へ保存する。元BPXテキストがある場合は原文とUTF-8
SHA-256も保存し、構造化JSONのハッシュと区別する。ブラウザー取込で原文と解析オブジェクトが一致しない場合は拒否する。熱形状を材料差分で変更した場合も、文献値・明示熱境界・材料差分のどれかを記録する。

C-rateのプレビュー・実行・SOC帳簿は同一の定格容量を使う。独自Nominal cell
capacityとBPX容量も接続した。eSOH平衡容量、正負極の理論容量、定格容量、実測SOH%は別の指標である。初期化学量論と実際の初期温度を保存する。初期OCVを指定した場合は専用eSOHのSOCから帳簿を開始する。

半セルの粒子＋電解液Li在庫はLi金属対極と交換する開放系であり、閉じた全セルのLi保存則を当てはめない。結果にscopeと適用外理由を保存・表示する。

円筒設計の写像はChen系の基準物性に限定する。LFP/NCA/BPX/半セル・独自差分には文献基準形状を使う。設計帳簿の仮定密度や比容量を他の物性セットへ自動転用しない。

## BPX依存と入力の扱い

既存の`.venv`と`.venv-research`の導入済みパッケージは変更していない。追加依存は`vendor/bpx`へ独立配置し、研究ワーカーだけが参照する。

再作成は`setup-bpx.ps1`。固定版は`requirements-bpx.lock.txt`、取得したホイールの名前・版・URL・SHA-256は
`docs/evidence/p4/bpx-dependencies.json`。BPX 1.1.1とPydantic等6パッケージを固定した。PyBaMM環境に既存のpyparsing/PyYAMLも使用する。依存欠落時は取込を拒否する。

BPX数式をPythonコードへコンパイルせず、ASTを走査してx・数値・四則・累乗・exp/tanh/coshのみ解釈する。属性アクセス、import、内包表記、任意呼出しを拒否する。BPXライブラリの関数変換口はワーカー内でこの解釈器へ置き換え、処理後に戻す。補間表も外挿しない。標準BPXの全拡張・複合相・熱モデル・Partial物性は今回の接続範囲外。

公式基準BPXは[pybamm-data v1.0.2](https://github.com/pybamm-team/pybamm-data/releases/tag/v1.0.2)の
`nmc_pouch_cell_BPX.json`。原本SHA-256は`cea07ea4fff9d667c2ad3fc430e699bb962a941051004dce52fddcd2d44ace3f`
で、固定版DataLoaderの登録値と一致した。原本のHeaderにある出典・熱物性が推定値である注記・Validationセクションを保持した。本実装でその実測曲線へのフィットを検証したものではない。

## 検証

- 全120ユニット/HTTP/保存/ジョブ回帰が成功。
- P4の実ワーカー31ケースを隔離DBで実行・保存・再読込。LFP/NCAの各3モデル、半セルSOC/OCV、4粒子近似と細メッシュ2件、輸送8方式、Si
  OCP3方式、方向別物性2方式、独自容量、OCP表、独自拡散係数、公式BPX。
- 各採用材料の基準結果JSONを`docs/evidence/p4/`に保存。容量換算、有限電圧、eSOH初期SOC、電極容量差、初期化学量論の範囲、JSON往復・DB再読込、材料入力ハッシュを確認。
- OCP補間と同梱関数の電圧差を10mV未満で照合。拡散係数変更が端子電圧へ反映されることを比較。BPXの元データが変換時に破壊されず、原本ハッシュが一致することを確認。
- EdgeヘッドレスのP4画面14件、既存P3画面13件が成功。物性19セット比較、絞込み、BPXファイル入力、出典/原本保持、プレビュー、設定復元、材料来歴、旧結果、プロジェクト切替、モバイル横はみ出しを確認。
- P1実ソルバ26ケース、P2実ソルバ13ケース、P3実ソルバ28ケースが期待状態で完了。禁止スキップ等は失敗を期待した検証。
- 既存Step 3実計算と取消・時間上限・再起動の回帰を実施。ライフサイクル3件は結果を誤保存せず期待状態で終了。
- JavaScript構文、Pythonコンパイル、`git diff --check`を確認。既存の未コミット変更を保持し、変更前ファイルをこのチャットの
  `work/original-backup`へ保存した。

二次・四次粒子近似のnative Li在庫集計にはメッシュ依存の誤差があった。今回の短い往復試験では二次が標準`7.18e-5`→細
`1.79e-5`、四次が標準`3.66e-5`→細`9.19e-6`に縮小した。標準メッシュでの在庫集計許容差はこれらの近似で`1e-4`、他の閉じた全セル経路では
`1e-5`とし、結果へ明記する。これは全条件での収束保証ではない。

検証スクリプト: `scripts/verify_p4_solver.py`、`scripts/verify_p4_ui.py`、`tests/test_materials.py`
。実行時はプロジェクト内TEMP/TMPを設定し、SSLKEYLOGFILEを解除した。通常運用DBへテスト結果を混ぜていない。

## 利用時と次の段階

サーバーを再起動し、画面を再読み込みする。材料物性の折りたたみを開き、文献セットを選び、必要なら出典・差分・追加係数を入力してプレビュー後に実行する。BPXはファイル入力から読み込む。

短時間の計算成功・保存整合・数値検証を確認した段階であり、対象18650/21700の実測校正・予測精度、寿命・析出量・安全限界を検証したものではない。係数を仮定したヒステリシス・輸送・方向依存の結果は未校正仮想セルとして扱う。次はP5aのSEI/析出/LAM等の単独機構。
