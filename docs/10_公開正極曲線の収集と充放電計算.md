# 公開正極曲線の収集と充放電計算

更新日：2026-10-16（JST）。カタログ `2026-10-16.1`、参照曲線エンジン `1.0.0`。

## 1. 今回追加した範囲

「公開正極曲線」タブから、NMC111・NMC523・NMC622・NMC811、Bare LCO・2%
LAF-LCO、LFP、LMFPを選択して単一CC充電／放電を計算する。8データセット・13本の正極枝・2,802節点、別に黒鉛OCP
791節点を同梱した。実行時のWeb接続やExcelライブラリは不要。

正極の対Li/Li⁺基準の上下限と、フルセル端子電圧の上下限を別の入力・停止条件とした。出典の有限電流曲線、加工OCP、図のベクトル読取を区別する。模式的な1RC、文献物性のSPMe/DFNとも別の計算方式である。今回の曲線をDFNの平衡OCP・拡散係数へ自動転用しない。

**要求された低電圧側1.5–2 Vの全範囲は埋まっていない。** 収録下端は約2.5–3.6 Vで、実データの端で止める。NMC111/523/622の高電圧側も4.4
V未満に収録端がある。未収録部分を計算値・実測値で埋めたようには表示しない。

## 3. 取得・加工とライセンス

カタログは [cathodes.v1.json](../pylibstudy/reference/cathodes.v1.json)
。各資料に取得日、URL、原本SHA-256、サイズ、ライセンス、出典、枝ごとの加工方法・点数を持つ。保存する計算JSONにも、使用した曲線全節点・原本ハッシュ・カタログ版とハッシュを複写する。更新後も過去結果は過去の曲線を保持する。

Nature Communicationsの3資料とWanデータはCC BY
4.0。著者・論文リンク・[ライセンス](https://creativecommons.org/licenses/by/4.0/)・加工内容を記録した。PyBEP由来のNMC111/523は
**CC BY-NC-SA 4.0** として別表示し、[元の利用条件](../pylibstudy/reference/PyBEP-LICENSE.txt)を同梱した。データセットごとに利用条件が異なる。

加工は次のとおり。

1. 出版社Excelはopenpyxlの読み取り専用モードで数値を読む。マクロ・OLEコードは実行しない。
2. LMFP/LFPはEMFのペン色と連結ポリラインを取り出す。3rdの色、容量軸の0/160 mAh/g、電圧軸の1.5/4.5 Vを原図で照合。LMFPは
   `xl/media/image29.emf`、LFPは`image35.emf`。
3. 同じ横座標や線が戻る箇所は、横座標が進む最初の値を採用し、除いた数を記録。縦の線を一価関数へ変換した点に注意する。EMF座標分解能は約1.393
   mV、容量はLMFP約0.0660 mAh/g、LFP約0.0738 mAh/g。これは信頼区間ではない。
4. 枝の通過容量を0→1に正規化。NMC622 OCPは`1 - sto`を充電方向へ変換。PyBEP座標も収録端間の相対状態として扱い、絶対Li化学量論組成とは置かない。
5. 直線補間の電圧差が原座標で最大0.5 mV以内になるよう節点を減らす。元の描画・測定精度が0.5 mVであるという意味ではない。
6. 黒鉛OCPは同じ座標の電位を平均し、昇順に整理。有効座標は約0.006279–0.985263。両方向で共用し、ヒステリシスを追加しない。

WanのZIPは約14.4 GBあるため全取得せず、HTTP RangeでZIP中央ディレクトリと必要な2 CSVだけを取得した。member CRCとSHA-256を照合し、
**ZIP全体のMD5は未照合**
と記録した。[範囲取得の記録](../pylibstudy/reference/acquisition.json)、[範囲読取コード](../scripts/remote_zip.py)を残した。

取得したが採用しなかった候補も区別する。RepOD `10.18150/JKHCAM` の取得NMCファイルは電圧・電流のみで、時間・容量・サンプリング間隔がないため容量曲線に使わない。Zenodo
`15012305` は索引上の主な内容がMPET計算とLFP実験であり、LMFP実測容量曲線として採用しない。行番号を時間に置き換えて容量を作ることはしなかった。

## 4. 計算式と有効範囲

単一の充電または放電枝に沿って進む。充電電流は負、放電電流は正。通過容量は絶対値、エネルギーは放電正・充電負。

```text
Qp [Ah] = 正極活物質質量 [g] × 採用枝の比容量 [mAh/g] / 1000
q [Ah]  = |I| t / 3600
zcharge = z0 + q/Qp
zdischarge = z0 - q/Qp
xn(t) = xn0 - I t / (3600 Qn)          (フルセルのみ)
Vterminal = Vpositive_reference(z) - Ugraphite(xn) - I Radditional
Eterminal [Wh] = integral(I Vterminal dt)/3600
Padditional [W] = I² Radditional
```

比容量がないOCPではユーザー指定値をQpの計算に使い、結果に`user_assumed_ocp_scale`
を記録する。有限電流の充電／放電で異なる比容量はそのまま保持する。独立した枝の相対状態なので、閉じたサイクルのLi損失・クーロン効率の予測には使わない。負極はQnと初期座標をユーザーが指定し、正極と同じ電荷量で更新する。

両電極の全ての補間節点で区切り、その間の直線上で電圧停止点を解く。出力間隔が粗くても電圧イベントを飛ばさない。エネルギーはその区間を台形積分する。正極または負極の収録端、対Li電圧限界、セル電圧限界、時間のうち最初の条件で終了する。初期状態が電圧窓の外なら0秒で終了し、自動的に初期座標を変えない。

追加抵抗は初期値0。有限電流曲線に既に含まれる分極を再加算する抵抗ではない。温度欄は参照測定の温度で、発熱後の最高温度を予測しない。電流を変えても曲線形状を変えず、進行速度を変更する。レート・温度依存性、CV保持、輸送・析出・劣化は未計算。

## 5. 操作

1. アプリを再起動し、「公開正極曲線」を選ぶ。材料、出典、温度、電流、グラフ、収録範囲を確認する。
2. 「対Li基準」または「セル端子電圧」を選択。セル端子電圧では負極Qn・初期座標とセル上下限を設定する。対Li上下限も別に有効。
3. 充放電、正極活物質質量、初期相対座標、電流を設定する。充放電を切り替えると初期座標は充電0.05／放電0.95、負極は0.1／0.9を初期値として適用する。
4. 必要なら「測定比電流を活物質質量に合わせる」を押す。例えばLMFP 10 gでは70 mA/gから0.7 Aとなる。
5. 「公開曲線でCC計算」を押す。終了理由、容量、エネルギー、正極参照電圧・負極OCP・端子電圧を確認する。LCO充電は4.55
   V、NMC811は4.4 V、LFPは3.7 Vに初期設定。LMFPは4.2 V付近だが、図抽出端の約4.199 Vで停止する場合がある。
6. CURVE VIEWの「結果と出典を保存」、CSV、JSON、条件復元、保存済み比較を使う。凡例に「対Li基準／セル端子電圧」を表示する。異なる基準の線を同じ電圧として解釈しない。
7. 正極参照データ自体は「参照曲線CSV」「出典付き曲線JSON」から出力できる。OCP資料には根拠のない比容量列を埋めない。

- [エンジン](../pylibstudy/cathodes.py)：標準ライブラリのみ、線形補間・電荷保存・独立電圧停止。
- [カタログ生成](../scripts/build_cathode_catalog.py)：開発時のみopenpyxlを使用。原本キャッシュは
  `data/reference/cathodes/sources`。
- [出典照合](../scripts/verify_cathode_sources.py)：原本7ファイルのSHA-256、13枝の全加工前座標で補間誤差を照合。
- [品質記録](evidence/cathode-curves/source-quality.json)：カタログハッシュ、点数、比容量、枝ごとの補間差。
- [単体テスト](../tests/test_cathodes.py)：8資料×充放電×2電圧基準、容量と負極の電荷保存、I²Rエネルギー差、停止イベントの出力間隔非依存、無効入力、保存・CSV来歴を確認。
- [画面検証](../scripts/verify_cathodes.py)：出典選択、個別の電圧停止、保存・復元、比較、ダウンロード、プロジェクト分離、390
  px表示。

$env:TEMP='G:\PyLIB_UI\.test_tmp'

Remove-Item Env:SSLKEYLOGFILE -ErrorAction SilentlyContinue

原本キャッシュを照合・再生成する場合はopenpyxlを含むPythonで`build_cathode_catalog.py`と`verify_cathode_sources.py`
を実行する。通常のUI起動・計算は再生成不要。これらの検証はデータ加工と実装の整合性の確認であり、対象円筒セルの実測精度や高電圧での材料性能を確認したものではない。

取得キャッシュの再現は`python scripts/fetch_cathode_sources.py --download-missing`
で行う。引数なしでは通信せず、既存7原本のサイズとハッシュを照合する。欠落ファイルだけを取得し、ハッシュ不一致は採用しない。既存キャッシュも不一致なら上書きしない。途中で取得が失敗した場合は、検証済みの原本を保持して停止する。

最終確認は標準テスト70件、公開正極画面8件、既存切替9件、既存設計画面8件。設計画面の警告セレクターは新しい曲線の警告と区別して確認した。大きな参照結果を送る際の受信待ちは、HTTP/1.1持続接続・明示的なContent-Length・エラー時の接続クローズに変更し、同一接続上の複数の大きなJSON応答もテストした。
